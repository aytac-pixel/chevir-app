`hand_landmarker.bytes`, `face_landmarker.bytes` and `pose_landmarker_lite.bytes` are Google's MediaPipe Tasks models (Apache License 2.0), the same files the web translator (chevirapp.com/tercume) uses, renamed from `.task` to `.bytes` so Unity imports them as TextAssets. The setup menu assigns them to `MediaPipeLandmarkProvider` automatically. The pose model gives the shoulders, arms and hips that the word model reads.
